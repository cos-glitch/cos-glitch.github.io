Machine Learning Based Biomarker Discovery for Pancreatic Ductal Adenocarcinoma Using Serum Metabolites

My thesis analysed serum metabolites found from performing untargeted metabolomics using LC/MS on serum from known pancreatic cancer patients. I built an ML pipeline in Python, from data loading and cleaning through model training and testing to final model results. An excel list of high impact metabolites were extracted and used for pathway analysis.

Genetic Epidemiology project on MELAS

Mitochondrial Encephalomyopathy, Lactic Acidosis and Stroke-like Episodes [MELAS] is a severe genetic disease. The mitochondrial dysfunctions are thought to be caused by mtDNA mutations, where MTTL1 gene is the most commonly mutated gene.

Breast Cancer Classification:

Python, SciKit, Jupyter, Pandas, SVM, Excel, Git, Github

A SVM model to predict Breast cancer from the Wisconsin Breast Cancer data set. Classifies whether a patient's diagnosis is benign (non cancerous) or malignant (cancerous).


Features:

  • Variable to set kernel type
  • Result export options:
    • .png of confusion matrix
    • .txt file containing confusion matrix, score and report
    • .xlsx file containing confusion matrix, score and report in three seperate sheets
  • Result Excel file contains formulas for quick analysis of multiple runs
